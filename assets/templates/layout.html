Settings are not protected by an admin key. Every operator route (Settings, Models, Logs, Security, Webhooks, API keys, Profile, domain presets, the analyzer and the worker diagnostics) is reachable without a token, and nothing is asked for. Set Protect_Settings_by_Admin_Key to 1 in config.php or .config.php to require the key from .admin.key again.
