RevoAp

Four layers from many answers to one

RevoAp: multi-LLM consensus platform with L1 parallel answers, L2 structural normalisation, L3 semantic consensus and L4 synthesis, plus REST API and SSE single-page UI.

What it does

  • L1 to L4 pipeline with an append-only audit trail
  • Durable worker queue for long model calls
  • REST API plus SSE interface, vanilla JS front end

Built with

CSS, HTML, JavaScript, PHP, PowerShell
