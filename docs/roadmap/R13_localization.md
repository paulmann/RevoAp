# R13 — Локализация RU/EN (поднять из P3-18)

ROLE: Senior frontend engineer specialised in i18n and content localisation (vanilla ES modules), with enough PHP 8.5 to serve translated strings and templates.

## Контекст проекта

ReVoAp — self-hosted консенсус-движок (PHP 8.5, без фреймворка, vanilla ES modules в `assets/js/`, шаблоны в `assets/templates/*.html`). Интерфейс и страница помощи — на английском, рабочий язык оператора — русский. Это трение при каждом обращении, а не косметика.

## Что уже есть

- Разметка: `assets/templates/layout.html`, `assets/templates/chat.html`, `assets/templates/help.html` (встроенная секция помощи, 12 разделов, в оглавлении), `assets/templates/shared.html`.
- Модули: `assets/js/app.js`, `pipeline.js`, `models.js`, `settings.js`, `history.js`, `logs.js`, `security.js`, `stats.js`, `statistic.js`, `model-selector.js`, `prompt-cache.js`, `copy-buttons.js` (последний менять нельзя).
- Стили: `assets/css/components/*.css`, темы `assets/css/themes/{dark,light}.css`.
- Серверные сообщения, видимые оператору: тексты провалидов, причины отказа прогона (`status_detail`), сообщения предполётной проверки, тексты диагностики воркера, Help.
- В ROAD_MAP локализация уже заведена как P3-18 — этот пункт её поднимает в приоритете.

## Цель

Интерфейс и помощь полностью переключаются между русским и английским; переключённый язык сохраняется.

## Объём работ

1. **Словарь строк** — единый механизм `t(key)` для JS и PHP с подстановкой параметров; русский и английский наборы в одном месте; отсутствие ключа видно (а не молча подставляется ключ).
2. **Переключатель языка** — доступен в интерфейсе, выбор сохраняется между сессиями; по умолчанию — язык браузера, при отсутствии совпадения английский.
3. **Покрытие интерфейса** — все видимые строки: шапка, чат, карточки прогона (включая состав участников и арбитра), вкладка Models и карточка Actualize, Settings, History, логи, безопасность, статистика, Help, подсказки и сообщения об ошибках.
4. **Серверные сообщения** — тексты, которые формирует сервер для оператора (причины отказа, предупреждения актуализации, диагностика), тоже переводятся; данные (идентификаторы моделей, коды провайдера, `not_in_catalog`) остаются как есть.
5. **Отчёт о покрытии** — простая проверка, перечисляющая непереведённые строки; полу-перевод хуже отсутствия перевода, поэтому непокрытые строки должны быть видны.

## Вне объёма

Перевод документации репозитория (docs/*.md) и CHANGELOG, третьи языки, автоматический машинный перевод.

## Ограничения и конвенции репозитория

- JS: рендер только через `el()`/`textContent`, **`innerHTML` запрещён** (проверяется харнессом) — то есть переводить надо текстовые узлы и атрибуты, а не HTML-шаблоны.
- CSS: только существующие токены из обеих тем (`tests/CssTokensTest.php`); новые классы — в стиле существующих.
- PHP: `strict_types`, `final class`, PHPDoc; без новых Composer-зависимостей; git не трогать; публичные контракты API только дополнять.
- Не трогать `.dev_agent/**`, `archive/**`, `vendor/**`, `Consensus-AI-main/**`, `cache/**`, `logs/**`, `assets/js/copy_to_clipboard.js`, `deploy/host/**`.
- `node --check` для ESM бесполезен — проверять через копии `.mjs`.

## Критерии приёмки

- Переключение языка меняет весь видимый текст, включая подсказки и сообщения об ошибках; данные (идентификаторы, коды) не переводятся.
- Выбор языка сохраняется между сессиями.
- Отчёт о покрытии показывает непереведённые строки, и их список пуст (или явно объяснён).
- Харнессы остаются зелёными на обоих языках.
